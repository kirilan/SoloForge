Solo Forge 是一款免费开源的 Android 健身应用，集间歇性断食计时器、热量与宏量营养素计数器、体重记录和训练计时器于一身。没有广告，没有追踪，完全离线。

它围绕本地数据所有权而设计：

* 没有后端
* 无需账号
* 没有统计分析
* 没有崩溃报告
* 已禁用 Android 云备份
* 可将全部数据备份和恢复为单个文件，并可选择自动备份到你指定的文件夹

功能：

* 间歇性断食计时器，支持 12:12、14:10、16:8、18:6、20:4 和 36 小时模式
* 根据断食状态发出提醒，而不是每天定时推送通知
* 使用你自己的 OpenRouter API 密钥分析食物照片
* 手动录入餐食，并可编辑营养素估算
* 本地设置热量和宏量营养素目标
* 带图表的体重历史记录
* 简单、间隔以及运动/休息三种训练计时器
* 仪表盘汇总断食、营养、体重、训练时长和连续天数
* 在进度日历上记录每日日记
* 可选的 Health Connect 同步体重和训练数据，体重秤或手环记录的数据无需重复输入

Solo Forge 只有在你开始分析食物照片时才会发出网络请求。该请求使用你提供的 API 密钥发送到 OpenRouter。所有已保存的餐食、体重记录、训练、断食历史、设置和导出文件都保留在你的设备上。

Solo Forge 基于 GPL-3.0 许可证发布。
