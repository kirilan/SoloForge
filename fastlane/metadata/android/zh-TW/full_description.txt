Solo Forge 是一款免費、開放原始碼的 Android 健身 App，集間歇性斷食計時器、熱量與巨量營養素計算、體重紀錄和訓練計時器於一身。沒有廣告，沒有追蹤，完全離線。

它以本機資料所有權為核心設計：

* 沒有後端
* 不需要帳號
* 沒有數據分析
* 沒有當機回報
* 已停用 Android 雲端備份
* 可將所有資料備份和還原為單一檔案，並可選擇自動備份到你指定的資料夾

功能：

* 間歇性斷食計時器，支援 16:8、18:6、20:4 和 36 小時模式
* 依據斷食狀態發出提醒，而不是每天定時推送通知
* 使用你自己的 OpenRouter API 金鑰分析食物照片
* 手動輸入餐點，並可編輯營養素估算
* 在本機設定熱量和巨量營養素目標
* 附圖表的體重歷史紀錄
* 簡單、間隔以及運動／休息三種訓練計時器
* 儀表板彙整斷食、營養、體重、訓練時間和連續天數
* 在進度日曆上寫每日日記
* 可選用 Health Connect 同步體重和訓練資料，體重計或手環記錄的資料不必重新輸入

Solo Forge 只有在你開始分析食物照片時才會進行網路連線。該請求會使用你提供的 API 金鑰傳送到 OpenRouter。所有已儲存的餐點、體重紀錄、訓練、斷食歷史、設定和匯出檔案都會保留在你的裝置上。
